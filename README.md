# Patch or Perish

A browser-based secure coding training game. Review fictional vulnerable snippets, identify the flaw and choose the safest patch. No snippets are executed.

## Run locally

Serve the repository with `python -m http.server 8000` and open `http://localhost:8000`. No dependencies or backend are required.

## Hosting

Suitable for GitHub Pages or any static host. Enable Pages from the `main` branch and root folder in repository settings.

Progress stays in your browser. Scores are for personal practice, not verified assessments.
